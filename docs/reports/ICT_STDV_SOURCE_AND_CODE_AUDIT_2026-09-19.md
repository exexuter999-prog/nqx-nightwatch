調査日: 2026-09-19 JST。用途: Claudeへの知識引き継ぎ。これは発注指示ではない。

## 1. 今回のSTDVの意味

対象は **TTradesが説明するICTのStandard Deviation Projections**。一定の値動きの幅を、Fibツールの係数で延長するもの。終値集合から標準偏差σを推定するBollinger Bands等とは別物であり、±2σの確率や正規分布の包含率を持ち込まない。

動画の説明・図示を確認したことと、取引の優位性を実証したことは別である。この調査では勝率、期待値、将来の到達確率を検証していない。

## 3. 実装に渡す数学的定義

ここからの数式表現と数値例は、図の配置を再現可能に記述したもの。

`p1` は掃引側の極値、`p0` はそのmanipulationレッグの出発点。数字はFibのラベルを表し、時系列の順番ではない。

```text
level(r) = p0 + r × (p1 − p0)

BUY投影:  p0 = 下方向のmanipulationが始まった高値
          p1 = その動きが掃引した安値
SELL投影: p0 = 上方向のmanipulationが始まった安値
          p1 = その動きが掃引した高値
```

`p0` は任意のEntryや反転後の到達点ではない。`-2` はp0から投影方向へ2幅、p1からは3幅離れる。「掃引極値から2倍」と実装すると1幅ずれる。

**合成値の検算例。実トレードではない。**

| 係数 | BUY: p0=20000 / p1=19980 | SELL: p0=20000 / p1=20020 |
|---|---:|---:|
| 1 | 19980 | 20020 |
| 0 | 20000 | 20000 |
| -1 | 20020 | 19980 |
| -2 | 20040 | 19960 |
| -2.5 | 20050 | 19950 |
| -4 | 20080 | 19920 |

これはリスク倍率Rではない。STDVの `-2` と `TP=2R` を混同しない。Rの分母は最終Entryと構造SLの距離で、投影幅とは独立。

MNQ向けの実装提案: 生の投影価格と0.25tickに丸めた価格を両方保持する。利確の実行価格を保守的に丸めるならBUYは下、SELLは上へ丸める。これは動画の指定ではなく実装側の選択で、既存丸め契約と比較して採用する。`-2.5` は幅が奇数tickのとき半tickになるため、テストが必要。

## 4. 出典だけでは決まらないこと

次は動画の裁量説明をコードにするための**未確定仕様**。Claudeが既存検出器と照合し、採用規則を先に文書化する。成果のよかった形へ後から変更しない。

1. manipulationの出発点を、どの確定スイングから選ぶか。
2. 掃引済み流動性のID、掃引と単なるブレイクの区別。
3. CISD/MSSの機械定義、確定に必要な足とその待ち時間。
4. wickによる極値とbodyによる箱の使い分け。
5. 複数アンカーの優先順位、寿命、無効化条件。
6. `-2.5` 超えのdisplacementの数値条件と `-4` へ進める条件。
7. NightwatchのTP1/runnerへ投影をどう対応させるか。

既存の確定済み検出器が必要情報を出せない場合は、その項目をMISSINGとして残す。未取得の2分足、未確定スイング、動画にない勝率を補わない。v1では6の自動化を見送っても、固定投影と位置の評価を完成できる。
