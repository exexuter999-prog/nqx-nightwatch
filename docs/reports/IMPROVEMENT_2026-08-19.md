## 1. 反省点(重大度順)

### 反省1 ★最重要 — 「指標停止」の誤判定(03:58〜04:25、10サイクル継続)

- **事実**: `data_get_study_values` が CVD −129,151 / VWAP 29,604.63 を約27分間返し続けた。
  CLAUDE.md §1「同一値が3回以上続く → 指標停止」を機械適用し、「3分ペインの指標停止」を
  Telegram に10サイクル報告し続けた。04:16 には「15分 SwingArm も停止」とまで拡大判定した。
- **実際**: 指標は正常稼働していた(ユーザー指摘で発覚)。
  `data_get_pine_tables study_filter="CVD"` の CVD Unified テーブルは生値
  (Δ CVD Day −133.567K)を返しており、**止まっていたのは読み取り経路(study_values のキャッシュ)**。
  その後 study_values も自然回復した。
- **何が問題か**: 裏取りせずに断定し、誤った状態をユーザーに送り続けた。
  保守側に倒れたので実害はなかったが、00:39〜01:21 の**真の停止**
  (VWAP が価格から500pt超乖離)と区別できる材料はあったのに使わなかった。
- **補足の誤り**: `NQX_DATA_LTF_SOURCE_TIME` は**スイング元バーの時刻**であり
  ハートビートではない。単独で「15分側も停止」の根拠に使ってはならない。

### 反省2 — priceAt を推定時刻で打った(02:46、market rejected)

- バーの Unix 時刻から推定した JST が実時計より約1分先行し
  `priceAt is too far in the future` で拒否 → frozen preview に落ちた。
- 同サイクル内にシステム時計で打ち直して回復。以後は**毎サイクル bundle 作成前に
  システム時計を取得**して priceAt/at に使用(恒久ルール)。

### 反省3 — Telegram 一時エラー時の再実行判断(03:55)

- `Remote end closed connection` は**送信前の失敗**だったため再実行で回復・重複なし。
- エラー文言から送信前/送信後を判別してから再実行すること。
  **送信後の失敗をリトライすると重複通知になる**(CLAUDE.md §7 の既知の罠)。

## 3. 改善指示(次セッションから適用)

### 指示A — 指標停止の判定手順(§1 の運用を改める)

「同一値3回」は**停止疑い**であって停止確定ではない。宣言前に必ず:

```
1. data_get_pine_tables study_filter="CVD" で CVD Unified の生値を確認
   (Bar/Day/Swing の Δ、EMA 判定が出る。ここが動いていれば指標は生きている)
2. 値の妥当性を確認: VWAP と現在価格の乖離が数百 pt あるなら真の停止を疑う
   (00:39 の真の停止は乖離500pt超で判別できた)
3. 両方が止まって初めて「指標停止」と報告する。
   1 だけ生きているなら「study_values の読み取り経路がキャッシュを返している」と
   正確に報告し、CVD 裏付けの判定は pine_tables の値で代替する
```

スクリーンショットは補助(ワイドモニターではアスペクト比の違いで右側が見切れる)。
メモリ `study-values-stale-snapshot.md` に同内容を記録済み。

### 指示B — ANCHOR_CONSUMED の扱い(今夜の主要ブロッカー)

今夜は連鎖が FLIP_HELD/blockerゼロまで完成しても `anchorOk=false`(ANCHOR_CONSUMED =
レベルを離れてから連鎖が完成する)で終わるケースが繰り返した(VAL 29,581・P:VAH 29,597)。

- この状態の武装機会は**レベルへの戻り(アンカー再生)だけ**。毎サイクルの
  `--level` 再評価は情報を生まない。
- 指示: HELD 到達済み+ブロッカーが ANCHOR_CONSUMED のみの場合、watching に
  「戻り待ち: レベル±tol」を明記し、**価格がそのゾーンへ戻るまで `--level` 再評価を
  省略してよい**。ゾーン到達時に必ず再評価+パスBを回してから判定する。

### 指示C — rb1R(第一バリアまでのR余地)を見送り根拠として明記する

今夜の `rrPotential` は rb1R 0.75〜1.06R が大半 = 最初の構造壁までのRが1R前後しかない
回転レンジだった。連鎖が通っても第一壁で1Rでは分が悪い。

- 指示: **rb1R < 1.0(tier≤3 の壁)のときは watching にその旨を1行書く**。
  武装には「壁を抜ける材料(rb2 までの走路根拠)」を追加で要求する。
- ADVISORY の範囲で運用する(拒否ゲート化するかは3セッション観測後にユーザー判断。
  R4/R8 の昇格手順と同じ扱い)。

### 指示D — 時刻・再実行の恒久ルール(反省2・3の手順化)

```
- priceAt/at は毎サイクル、bundle 作成直前のシステム時計で打つ(バー時刻から推定しない)
- publish 失敗時: エラーが「送信前」(market rejected 等)なら修正して再実行。
  「送信後」(state 書き込み失敗等)なら再実行しない(重複通知)。判別できない場合は
  Telegram の実着信を確認してから決める
```

## 4. 戦略面の反省(R9 の議題候補 — 導入はユーザー判断)

### S1 — 確認連鎖のレイテンシと回転の半周期が同スケール(今夜ゼロトレードの構造的理由)

今夜のレンジは約50pt(29,564〜29,614)・ノイズ床14〜18pt。MSNR の完全確認
(ブレイク→受容→リテスト保持)には3〜5本=スイングの15〜25ptを消費する。
実測: 03:48〜03:55 の下げ(VAH 29,597→29,565、33pt)で FLIP_ACCEPTED が出たのは
03:58・価格29,573 — **33ptの脚の25pt目**。確認が終わる頃には回転が折り返すため、
ANCHOR_CONSUMED / rb1R<1 で全て止まった。**この型は回転レジームでは
「勝てない」のではなく「参加できない」— それは設計どおり**。
改善: 毎サイクル個別ブロッカーを再導出するのではなく、
「レンジ幅 < 3×ノイズ床 かつ 回転持続」を検知した時点で
**「不参加レジーム」を早期宣言**し、解除条件をレンジ外の受容だけに絞る。

### S2 — 02:20 取り下げの解剖(構造固定 Entry の限界)

取り下げ自体は正解: Entry 29,633 に価格は二度と触れず(以後の最高値 29,614.75)、
**約定機会も取り逃した利益もゼロ**だったことを確認済み。
一方で価格は 02:20 の29,616 から 03:09 の29,548 まで **69pt 下げて TP ゾーンを通過**した。
構造に固定した Entry は「構造の近くから始まるスイングしか取れない」。
論点: 取り下げ後に **Entry を直近の下位構造へ再アンカーする手順**
(今夜なら VWAP/LTF Fib 29,599〜29,605 の戻り売り)を正式化するか。
ただし今夜は再アンカー先も NO_DISPLACEMENT で止まり rb1R≈1 だったので、
導入しても取れた保証はない。3セッション分の観測を貯めてから判断。

### S3 — 方向整合(CT_TREND 一致)の絶対化

今夜最良のシグナルは **03:12 のスプリング**(VAL 29,580.6 の下抜けを下ヒゲ33ptで
即回収+CVD −149,200→−127,853 の +21k)だったが、15分全時間足 −1 で門前払い。
正直な損得: その後の上値は 29,614.75 止まり(POC 29,634 未達)なので
取れても最大+34pt≒1R強 — 大きな取り逃しではない。
ただしこれは 8/12 の勝ち型(合流帯反発買い)と同型で、現行ルールでは
「トレンド夜には反転型を一切取れない」。条件付き例外
(tier≤2 レベル + CVD ダイバージェンス + displacement reclaim、TP は POC まで、
緩衝は3分ノイズ床)を ADVISORY で3セッション観測 → 昇格判断、が R9 候補。

### S4 — ボラ予算ゲートの盲点(「走路」を見ていない)

比率 0.26〜0.34 で終夜「通常運用」だったが、実際は取れない夜だった。
現ゲートは**ノイズ vs SL予算**しか見ておらず、**走路 vs ノイズ**(rb1R)を見ていない。
今夜の rb1R は 0.75〜1.06 に張り付き、これが実質の拒否理由だった。
**走路ゲート: 「rb1R ≥ 1.0(tier≤3 の壁)」を武装要件に加える**のが R9 の最有力候補
(§3 指示C の ADVISORY 運用の昇格版。今夜の全ブロックと整合し、8/12 の勝ち
トレードは rb 走路が開いていたので通る見込み — 要バックテスト)。

### S5 — 時間帯の期待値

変位が実際に出たのは NY 寄り付き周辺(22:30〜23:30)と 03:48〜03:55 のみ。
02:00 JST 以降の午後回転で反応型が成立した実績が乏しい。
監視は継続してよいが、**02:00 以降は rb2 走路(≥2R)がある場合のみ武装検討**の
重み付けを検討する。
