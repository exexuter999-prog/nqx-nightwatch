# R64 — カード背景の鉄粉(インタラクティブな背景)

2026-09-06 ユーザー要望: 「カードの背景をインタラクティブに何か面白いものを実装して」。

## 何をしたか

黒鉄のカード(R59)の面に **鉄粉**を眠らせた(`telegram_mini_app/cardfield.js`)。

- 14px 間隔の格子(一行おきに半格子ずらした六方に近い並び)に、5px の短いダッシュ。眠っているときは
  研磨目に沿ってほぼ水平(粒ごとに ±28° 散る、決定的な擬似乱数)、骨色 7.5% の薄さ。
- 指やポインタが近づくと、鉄粉は**磁極へ放射状に並ぶ**(磁力はガウス、σ = 92px)。鉄粉には極性が
  無いので、向きの差は [−π/2, π/2] に畳んで最短側へ回る。芯ほど濃く(50%)、骨色から朱へ。
  磁極の下には朱の柔らかい灯り。
- 離すと 1.4 秒で眠りへ戻る。タップ(pointerdown)すると波紋が鉄粉の列を走る(0.9 秒)。
- canvas は 1 枚。カードは `isolation: isolate`、canvas は `z-index: -1` で **面の上・本文の下**。
  `pointer-events: none` でイベントはカード本体が受ける(スクロールを邪魔しない。`touch-action` は触らない)。
- 動くのは触れている間と緩和・波紋の間だけ。何も無ければ静止画 1 枚で RAF を止める(電池)。
  `prefers-reduced-motion` では静止した鉄粉だけ(反応の listener を付けない)。
- 対象は `.state-card:not(.empty)`(シナリオ・建玉・GATES など)。待機紋章のカードには敷かない。
  カードは render ごとに innerHTML で作り直されるので、app.js が描いた直後に `attachCardFields()` を呼ぶ。

**表示専用**: view・注文・保存・ネットワークに触れない(テストで禁止語を検査)。

## 同日の追補: WebView クラッシュ対策(寿命の整理)

デプロイ直後に Telegram の WebView が落ちた(再起動で復活)。WKWebView はメモリ超過で落ちるので、描画
(innerHTML)ごとに積み上がる資源を潰した:

- **鉄粉**: ResizeObserver を廃止(消えたカードと canvas を掴み続けていた)。触れたときに寸法を測り直す。
  `attachCardFields()` は DOM から消えたカードの鉄粉を片付ける(canvas の bitmap を 0 に)。DPR は 1.5 まで。
- **シナリオのチャート**: `render()` が毎回作り直していたのを、`scenarioChart.mount` を新しいカードへ
  `replaceWith` で差し戻して使い回す(氷の WebGL コンテキストが描画ごとに増えない)。
- **氷**: `destroy()` で `renderer.forceContextLoss()`、RAF は氷があるときだけ、DPR 1.5。目も DPR 1.5。
- 検証: デモで場面を 6 回切り替えても canvas は 5 枚で一定、シナリオのチャート要素は同一、runtime error 0。

## 同日の追補(バグ狩り): 緩和が段階的でなかった

「離すと 1.4 秒で眠りへ戻る」つもりが、実装は「最後に触れてから 1.4 秒は磁力 1、その後いきなり 0」
(緩和の変数は active が偽のとき常に 0 で、死んでいた)。さらに pointerleave は「最後に触れた時刻を今に
置き直す」だけで、離した瞬間からもう 1.4 秒磁力が掛かり続けていた。`held`(触れている間 1)と
`releasedAt`(離した時刻)に分け、`magnetStrength(held, sinceReleaseMs)` が離してから RELAX_MS かけて
直線で 0 へ落とす。指(touch / pen)は pointerup でも離す(マウスはカードの上に居座るので leave まで保つ)。
止まった指の下では向きが揃い切る 0.7 秒で RAF を止め、磁力は掛かったまま静止画で残る。テストが強さの
曲線と離す経路(leave / cancel / up)を検査する。
