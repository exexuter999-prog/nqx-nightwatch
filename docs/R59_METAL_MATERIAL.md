# R59 — METAL: 面の材質(Mini App)

2026-09-05 ユーザー要望: 「最新技術を駆使してこのアプリの全体的な『平坦感』をなくし、
メタルチックな質感にアップグレードして欲しい」。

## 何が平坦だったか

面が単色(`--bg-1`)の板で、縁に厚みが無く、光の向きが無い。R53 の「上辺 1px の光」だけでは
面が起き上がらなかった。

## どう直したか(`telegram_mini_app/styles.css` 末尾の R59 節、DOM は `.grain` 1 枚だけ追加)

面ごとに 5 層を重ねる。画像は使わない(ビルド予算・オフライン耐性)。

| 層 | 実装 | 効果 |
| --- | --- | --- |
| 地金の勾配 | `--steel`(上明・下暗の 3 段。`oklch()` 対応なら oklch のトークン) | 板に厚み |
| 研磨目 | `--brush`(3px と 11px の二周期の `repeating-linear-gradient`) | ヘアライン仕上げ。周期をずらしてモアレを避ける |
| 光沢 | `--sheen`(左上からの斜光 + 上辺に沿う帯状反射の `radial-gradient`) | 光の向きが決まる |
| 面取りの縁 | 透明 1px border に `border-box` 原点のリム勾配 `--rim`、内側は `--bevel`(上=光・下=影・左右微差) | 削り出しの縁 |
| 粒子 | `.grain`(fixed、`feTurbulence` を 160px タイルに一度だけ焼いた SVG data URI、opacity .075) | 金属面のざらつき |

適用面: `.panel` / `.state-card` / `.rd-card` / `.route-lane` / `.ledger-stat` / `.lifeline-cell` /
`.watchtower`(帯は色付き縁を残して面だけ研ぐ: `.decisive-rail` / `.autotrade` / `.demo-banner`)。
小タイル・チップは向きの色を残して縁の面取りだけ。文字はキャップスを刻印(`--engrave`)、
値を浮き文字(`--emboss`)。ボタンは朱の削り出し(`color-mix()` で上辺白熱・下辺沈み)、
スライダーのノブと設定スイッチのノブはクロームの丸。ドックは `@property --dock-angle` で
リムの反射がゆっくり回る(唯一の動き、`prefers-reduced-motion` で止まる)。RADAR の LAST は
残高と同じクロームの地金。

**変えていないもの**: 寸法(`--s-*` / `--t-*`)、配色の役割(acid = 武装・発注可・利益)、
AUTO カードの鮫肌、ULTRA の虹の縁、コーナーエンバー。信号を持つ影(`.state-card.armed` の
グロー、`.lifeline-cell.is-drained` の錆の縁、WATCHTOWER の沈黙/HALT の錆)は材質の上に戻してある。

## 第 2 版(同日夜): 線からサテンへ

ユーザー評「シックだがちょいオールド。金属感が線頼り。もう少し高級感」。高級な金属は線ではなく
**滑らかな面の光**で分かる、と読み替えて次を入れ替えた。

| 第 1 版 | 第 2 版 |
| --- | --- |
| ヘアライン研磨目(3px / 11px の筋) | 廃止。段の無いサテン地金 |
| 上→下の直線的なリム | 縁の光: `conic-gradient` で左上(315deg)が最も明るく、右下(135deg)に小さな照り返し |
| 純白のハイライト | 骨色(bone)寄りのハイライト(シャンパン・チタンの温度) |
| 斜光 1 本 | 左上のソフトボックス(大きく柔らかい radial)+ 右下の照り返し + 斜光の陰影 |
| 上辺光 + 下辺影 + 左右のリム 4 本 | 上辺光 1 本 + 下辺影。接地の影と環境の影の二段で浮かす |
| ドックの conic リムが回る | 動かない。ドック・ピル・WATCHTOWER は曇りガラス(`backdrop-filter`)で後ろの光を受ける |
| 粒子 .075 | .045 |
| 朱ボタンに硬い面取り(inset 黒 2px) | 左上の柔らかい光と薄い沈みだけ |

## R63(2026-09-06): 縦ドックの作り直し

1100px 以上で左端に立つ縦ドックは、曇りガラスの 1 本の管に背後のオーロラが斜めの光筋として透け、
「金属管」に見えていた(ユーザー: かなりダサい)。管をやめ、**1px の光のレールに削り出しの丸いキー**を
並べる: キーは黒鉄のサテン(50px)。押されていないキーは沈み(内側の影)、アイコンだけで文字を持たない。
選ばれたキーだけが起き上がり(外側の影 + 3px 前へ)、朱の輪を灯し、縦長(54×66)に伸びて名前を現す。
管も曇りガラスもここでは使わない。横並びのドック(電話)は R59 のまま。styles.css 末尾の R63 節。

## 落とし穴

- CSS コメントの中に `--s-*/--t-*` のような **`*` と `/` の並び**を書くとコメントがそこで閉じ、
  直後の `:root` トークン群がまるごと無効になる(ビルド警告 `Unexpected "*"`)。最初の確認は
  トークン無しの薄い状態を見ていた(2026-09-05 実測)。トークン名はコメントでは言葉で書く。

- ワードマークは `logo.js` が SVG 紋章 + `.logo-word` に組み替える。文字を透明にしてクロームを
  掛けると**消える**(実測)。触らない。
- `.panel.cut::before/::after` と `.state-card::before/::after` は既に使われている(エンバー・
  上辺の光)。材質は疑似要素を足さず、`background-image` の多層と `box-shadow` だけで作る。
- `background` の**ショートハンド**を持つ状態(`.decisive-rail[data-status=pass]`、
  `.command-btn.is-on` 等)は `background-image` を打ち消す。必要なら個別に再指定。
