# R60 — 待機紋章の目(3D 眼球)

2026-09-06 ユーザー要望: 「中央の赤い目のところを 3D で細かく作り込んで」→ 続けて
「瞳孔を開かせて赤目じゃなくて黒目に、白目を充血させて」「もっと黒目は黒くリアルに、
白目は明確に充血」「もっと両側を充血させて」「茶色の外枠をもう 2 段階黒くして」。

## 何が変わったか

NO SCENARIO のとき WATCH の中央に出る紋章(環・目盛・七芒星 + 54px の線画の目)のうち、
**目だけを Three.js の眼球**にした(`telegram_mini_app/eye3d.js`)。環と星の SVG はそのまま
下に残り、`.standby` は 136 → 160px。WebGL が無い端末では線画の目が残る。

| 部位 | 作り |
| --- | --- |
| 眼球 | 1 枚の ShaderMaterial。光軸からの角 θ と方位 φ で強膜/虹彩/瞳を切る |
| 虹彩(黒目) | 散大した瞳(角半径 0.40 / 虹彩 0.56、武装で 0.46)の外に残る細い環。**茶を含まない**灰黒の放射繊維・粒・クリプト・襞(光が当たった所だけかすかに灰に浮く)。輪部は黒へ沈む。自発光は瞳の縁の残り火だけ(neutral 0.05)。**中央に鏡面反射は載せない**(鏡面は強膜のみ) |
| 強膜(充血) | 中立の白地に 3D ノイズの 0.5 等高線で血管 3 階層(幹・枝・毛細血管)。**両側(目頭・目尻)ほど太く濃く**、全体に赤く滲み(flush 0.12〜0.78)、輪部の手前だけ白を残す |
| 角膜 | **置かない**。透明球 + 映り込みの版は、白地だと瞳が灰色に濁り、黒地でも中央に catchlight が残った → 「眼球中央の光の反射を無くして」で撤去 |
| 瞼 | 目尻(±67°)と縁の頂点(上 30° / 下 24°)を通る球面上の円で切った球帽 `lidCircle()`。黒鉄(0x08090b、環境反射 0.7)、縁に鈍い金属の lip。まばたきは上瞼が約 54° 降りる |
| ベゼル | 黒鉄のトーラス 2 本(外 1.2 / 内 1.125)。眼窩は暗幕の円盤 |
| 光 | 中立の白のキー(暖色は黒鉄を茶色に見せる)+ ごく弱い朱のリム(0.3)+ 中立の白/灰だけの環境 + 弱いブルーム |

**生きている手掛かり**: サッケード(1.8〜4.5 秒ごとに ±14°/±9° へ臨界減衰ばねで跳ぶ)、
固視微動、まばたき(3.8〜9 秒、18% で二度)、瞳の呼吸(4.2 秒)、ポインタ追従(近いときだけ、
2.5 秒で戻る)。`prefers-reduced-motion` では静止画を 1 枚描くだけ。

**表示専用**: view・注文・保存・ネットワークを読まない(テストで禁止語を検査)。app.js は
empty card を描いた直後に `standbyEye.attach(.standby)` を呼び、カードが消えれば detach。
WebGL コンテキストは 1 つを使い回す(innerHTML で消えた canvas を次の host へ移す)。
画面が隠れているとき(IntersectionObserver / visibilitychange)は描かない。

部分を無くして」「瞼の輪郭が瞬き時に浮き上がるバグ」「瞼に厚み」。

| 瞼の重さ | 無し | `DROOP`: 常に 0.16〜0.24 落ち、7〜14 秒に一度 0.5〜0.68 まで落ちて 1.4 秒留まる |

| 白目 | 中立の白、輪部の近くは白を残す | **浅黒い地(0.60)に全面の濁った赤**、輪部の際まで暗紅の血管。きれいな白は無し |
| 光 | 左上から 2.2 | 上から弱く 1.7、環境光 0.25(ローキー)。上瞼の下に影の帯 |
| 瞼の作り | 球帽を x 軸で**回す** → 目尻が動いて輪郭が浮いた | **球を平面で切る**(`lidPlane` + `clippingPlanes`)。平面は常に目尻 2 点を通り、まばたきは縁の頂点だけ動く。`renderer.localClippingEnabled` |
| 瞼の厚み | 縁の細線(0.016) | 上瞼: 殻 1.09 + 丸縁 0.048、下瞼: 殻 1.06 + 丸縁 0.034。丸縁の内周は眼球の中(半径 < 1)まで食い込ませ、縁と眼球の隙間(「浮き」)を消す。上瞼の殻を大きくして目尻の z-fight を避ける |
| 接触の影 | 無し | 瞼の平面を眼球シェーダへ uniform(`uUpperPlane` / `uLowerPlane`)で渡し、縁の直下ほど暗く(上 0.62 / 下 0.34)。瞼が眼球に「乗っている」ことが影で分かる |
| 瞼の艶 | 黒鉄 roughness .36 | 上 .58 / 下 .74(艶消し)。ドームに白い反射の玉が乗らない |

## 第 3 版(同日): 瞼の視線連動と外枠の統合

- **瞼は視線に連動**(「上を見るときは瞼を開ける」): `lidOpening(pitch)`。上を見ると上瞼が視線の
  1.8 倍上がり、瞼の重さ(DROOP)が抜ける。下を見ると上瞼が少し追い、下瞼が少し下がる。
- **背面の平面を全部消し、回転する外枠を 3D に統合**(「背面の平面の目を全部削除して、回転する
  外枠も目と統合」): `.standby.has-3d` で SVG の環・目盛・七芒星・線画の目を全て隠し、3D 側に
  黒鉄の外環(1.42)・15° ごとの目盛(45° ごとに長い、暗紅の残り火)・七芒星 {7/3}(1.33、淡い
  ワイヤー)を組んだ `orbit` グループを置く。80 秒で一周(旧 CSS と同じ)、視線に 0.35 倍だけ
  傾いて付いてくる(眼球と一体の器具)。reduced-motion では回らない。WebGL 無しは SVG が残る。
- 描画ループの関数名が `frame` なので、外枠のグループは `orbit`(同名で SyntaxError を踏んだ)。

## 起動直後の一瞬(2026-09-06 ユーザー報告)

3D は後読みなので、届くまで SVG の旧紋章が先に描かれて一瞬見えていた。app.js が起動時に WebGL の
有無だけを同期で調べ、使える端末では empty card の `.standby` に `is-3d-pending` を付ける。CSS は
pending の間、平面(環・目盛・線画の目)を隠し、3D の閉じた目と同じ見え方の黒鉄の玉(`::before`)を
置く。3D が attach されると `has-3d` で玉は消える。モジュールが読めない・NOOP(WebGL 不可)なら
`standbyFallbackToFlat()` が pending を外して平面へ戻す。

## 予算

`eye3d.js` は後読み(dynamic import)。`three` は `three-renderer` チャンクを scene3d と共有するので
増分は 13 kB。起動チャンクは変わらない。

## 落とし穴

- 角膜の地色を白にすると瞳が灰色になる。黒地でも中央に catchlight が残る → 角膜そのものを置かない。
- 細い血管を何層も重ねると小さい画面では桃色の靄になる。線として見える太さ(0.017〜0.024)を守る。
- 暖色のキーライト・朱のリム・朱の環境帯は、黒鉄の瞼・ベゼルと灰黒の虹彩を**茶色**に見せる
  (ユーザー指摘 ×2 → 光と環境を中立の白/灰に、リムは 0.3)。
