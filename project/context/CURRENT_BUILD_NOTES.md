## 直近の実装

### NQX高速出力

- Uplinkの既定モードを `FAST / EXECUTION NQX` に設定
- `DEEP / FULL AUDIT` を選択可能
- FAST専用の短縮プロンプトを実装
- 旧フルプロンプト比で文字数を約32%削減
- FAST画像は長辺最大1,280px、JPEG品質0.86へ変換
- DEEP画像は長辺最大1,600px、JPEG品質0.92
- 同系統の参考画像3枚では、FAST画像ペイロードが元PNG合計の概算約50%まで減少
- FAST出力上限2,200トークン、タイムアウト75秒
- DEEP出力上限3,400トークン、タイムアウト120秒
- 実行秒数、送信量、VALID / ERRORをUplink内に表示
- FASTは余分な起動アニメーションを省き、検証後すぐ描画

### 安全ゲート

- 生成結果へ `validateNQX()` を即時実行
- 構文エラーがある生成物は入力欄に保持するが、登録済み分析を上書きしない
- レベル優先、構造的SL、Invalidation順序、R:R、イベント処理、排他条件をFASTでも必須化
- スクリーンショット分析では勝率や未検証統計を生成しない
